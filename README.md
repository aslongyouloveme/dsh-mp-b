## 简单脚本 demo

一个命令行问候示例，演示参数解析和终端输出。需要 Python 3，无需安装第三方依赖。

在仓库根目录运行：

```bash
python3 scripts/hello.py
# 你好，世界！这是项目 B 的脚本 demo。

python3 scripts/hello.py --name 小明
# 你好，小明！这是项目 B 的脚本 demo。

python3 scripts/hello.py --help
```

名字中包含空格时，请加引号，例如 `--name "Project B"`。
